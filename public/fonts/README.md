# Helvetica Now Display Font Setup

Place the following Helvetica Now Display font files in this directory:

- HelveticaNowDisplay-Light.woff2 (weight: 300)
- HelveticaNowDisplay-Regular.woff2 (weight: 400)
- HelveticaNowDisplay-Medium.woff2 (weight: 500)
- HelveticaNowDisplay-Bold.woff2 (weight: 700)
- HelveticaNowDisplay-ExtraBold.woff2 (weight: 800)

If you don't have these files, the system will fallback to system-ui and Arial.

Note: The hero section heading uses font-extrabold (800 weight).
